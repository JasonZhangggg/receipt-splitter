# Everyone with the link has equal access, except to payment handles

There are no accounts and no host key. Anyone with a Split's link can edit its Items, prices and Adjustments, add Participants, and Claim any Item for anyone, the Host included. We chose simplicity over control because a Split is shared by a group of friends: to protect against mistakes, it keeps a recent-changes list with undo, and the Total check catches bad prices. The one exception is the Host's payment handles. They are entered when the Split is created and can only be changed from the device that created it, because an edited handle would send everyone's money to someone else.

A Split has no verification beyond the link, because it is between friends. Any device can take any name with **That's me**, and nothing checks who asks. The pick is not recorded in History. Any device can record or clear anyone's Payment, and a Payment cannot be reverted from History. History shows who recorded it, so a wrong mark can be traced and cleared. The Payments sheet guards against slips instead of the server: the Host and the person themselves check a name off directly, and anyone else is asked to confirm first. The takeover is the `pick` operation with `takeOver` in `src/core/operations.ts`. We dropped the earlier rule that only the payer's or the Host's device could record a Payment: it was never a security boundary, because any device can take the name first, and a confirmation stops the same honest mistakes without locking anyone out.
