# Home page design

The approved design for the home page `/`, from the operator's six prototype rounds on 2026-09-30. This is a static sketch, not app code. RS-6 and RS-7 build from it.

- `idea2.html` is the design. Serve the repository root over HTTP and open `docs/design/home/idea2.html?s=empty|reading|read|ready|link&t=light|dark`. Widths of 900 px and up get the desktop layout.
- `idea2.png` is its contact sheet.
- `tokens.md` holds the colors, type sizes and contrast table.
- `layout.md` holds the layout, the states, the motion notes and the reasons the tip section and payment fields were cut.
- `fonts/` holds Plus Jakarta Sans 400 and 500 under the SIL Open Font License (`fonts/OFL.txt`).

Changes after the sketch, decided by the operator: no PDF upload in v1, no "photo stays on this phone" line, and a slightly taller bottom sheet. `tokens.md` and `layout.md` predate these decisions where they mention PDF.
